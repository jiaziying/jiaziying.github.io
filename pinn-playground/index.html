02 / UNDER THE HOOD

How does a PINN learn from physics?

Follow one prediction through the network, the governing equations, and the training objective. Each step is general: it applies to many differential-equation problems.

Same neural network. One additional source of supervision.

A PINN can use a familiar MLP or another architecture. What changes is how the network learns: measurements and mathematical constraints guide the same trainable parameters.

THE BIG IDEA

Represent an unknown physical field with a neural network

Just like a conventional neural network, a PINN maps input features to an output. For time-dependent physical systems, those features are often position and time.

What is θ?The learnable network parameters.
What is uθ?The model's current approximation of a quantity we want to know.
But if observations are scarce, how do we know whether these predictions make sense? Physics adds constraints.
STEP 02 · THE PHYSICAL PROBLEMFour sources of information
Where do the constraints come from?
PDE / interior points · Check the governing equation at locations without requiring the true solution there.
NOT EVERY TERM IS REQUIRED FOR EVERY PROBLEM

Physical laws and conditions define a valid solution

∂

Governing equation (PDE)𝓕[u; z, μ] = 0 inside the domain. This is the governing PDE.

t₀

Initial conditions (IC)u(x, t₀) = u₀(x), for a time-dependent problem.

∂Ω

Boundary conditions (BC)𝓑[u] = g on the spatial boundary ∂Ω.

●

Observed data (optional)Known values yᵢ at selected coordinates zᵢ.

The PDE tells us how a solution should behave; IC, BC, and any observations help select the solution relevant to the problem.

The residual measures how far the predicted function is from satisfying the governing equation at sampled points.
THE “AHA!” MOMENT

Physics can supervise the model without exact solution labels

Automatic differentiation computes derivatives of the network output with respect to its inputs. We substitute those derivatives into the governing PDE.

Small residualThe prediction approximately satisfies the equation at that sampled point.
Important limitationA small PDE residual alone does not guarantee the correct solution; initial and boundary conditions still matter.
The physics residual becomes one training signal alongside the other constraints.

THE GENERAL PINN OBJECTIVE

Train against the physical constraints

ℒPINN = λfℒphysics + λICℒIC + λBCℒBC + λdℒdata

Each term penalizes a different requirement. Which terms appear—and their weights—depend on the problem. Observations are optional in a physics-driven forward PINN.

How is each loss computed? ⌄
Physicsmean |𝓕[uθ](zf)|²
Initial conditionmean |uθ − u₀|²
Boundary conditionmean |𝓑[uθ] − g|²
Optional datamean |uθ(zd) − y|²
Automatic differentiation, againFirst it provides input derivatives for the PDE residual. Then backpropagation computes gradients of the total loss with respect to network weights θ.
Not a magic guaranteeBalancing constraints, sampling collocation points, and optimization can all affect accuracy.
✦
What makes a PINN different?

It is the training constraints, not a special network layer. The same architecture can be trained with or without a physics residual term.

What if the physics we teach the network is wrong?

Two actual PINNs were trained with identical MLP architecture, initial weights, observations, sampling schedule, optimization budget, and physics-loss weight (λ = 0.3). One was given the correct wave speed c = 1.0; the other was trained with the deliberately incorrect speed c = 0.55. Both are evaluated against the same true reference.
